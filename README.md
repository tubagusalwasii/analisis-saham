# Stock Market Analyzer

Sebuah aplikasi berbasis Python untuk melakukan visualisasi dan analisis teknikal pada data pasar saham secara *real-time*.

## 🚀 Teknologi yang Digunakan
- **Bahasa:** Python
- **Data Source:** yfinance (Yahoo Finance API)
- **Visualisasi & UI:** (Sebutkan misal: Streamlit / Matplotlib / Pandas)

## ✨ Fitur Utama
- Mengambil data riwayat harga saham secara dinamis.
- Memvisualisasikan pergerakan harga (*candlestick* / *line chart*).
- Mendukung analisis teknikal dasar.

## ⚙️ Cara Menjalankan Aplikasi
1. Clone repository ini.
2. Install dependensi: `pip install -r requirements.txt`
3. Jalankan aplikasi: `python app.py` (atau `streamlit run app.py` jika pakai Streamlit).
